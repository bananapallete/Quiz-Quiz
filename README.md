# 🎉 퀴즈퀴즈 (Quiz-Quiz)

친구들과 함께 즐기는 **실시간 파티 퀴즈**.
참가자는 휴대폰으로, 진행자는 노트북으로 접속합니다.

---

## 빠른 시작

```bash
npm install
npm start
```

서버가 켜지면 터미널에 접속 주소가 표시됩니다.

| 역할 | 주소 |
| --- | --- |
| 참가자 (휴대폰) | `http://<노트북IP>:3000` |
| 진행자 (노트북) | `http://<노트북IP>:3000/admin` |

친구들과 **같은 와이파이**에 연결한 뒤 참가자 주소를 알려주세요.
밖에서 접속해야 한다면 `ngrok http 3000` 같은 터널링 도구를 쓰면 됩니다.

관리자 비밀번호 기본값은 `admin1234` 입니다. 바꾸려면:

```bash
ADMIN_PASSWORD=원하는비밀번호 PORT=3000 npm start
```

> 집 안 와이파이에서 쓸 때는 기본 비밀번호도 괜찮지만,
> **인터넷에 배포할 때는 반드시 바꿔야 합니다.** 아래 [온라인에 호스팅하기](#온라인에-호스팅하기) 참고.

---

## 온라인에 호스팅하기

이 앱은 **실시간 WebSocket 서버**입니다. 그래서 **GitHub Pages · Netlify · Vercel 로는 배포할 수 없습니다.**
(정적 파일 호스팅이거나 요청이 끝나면 종료되는 서버리스 방식이라, 연결을 계속 유지할 수 없습니다.)
Node 서버를 계속 띄워주는 곳이 필요합니다.

### 방법 A. 노트북에서 실행 + 터널 (파티 당일에 가장 추천)

배포 없이 **명령어 한 줄로** 지금 켜둔 서버에 인터넷 주소를 붙여줍니다.

```bash
# 1번 터미널
npm start

# 2번 터미널
cloudflared tunnel --url http://localhost:3000
```

`https://xxxx-xxxx.trycloudflare.com` 같은 주소가 나오면 친구들에게 그 주소를 보내면 됩니다.
(`cloudflared` 설치: macOS `brew install cloudflared` / Windows `winget install cloudflare.cloudflared`)

- 👍 회원가입·배포 불필요, 서버가 잠들지 않음, **점수가 내 노트북에 저장되어 안전**
- 👎 노트북을 켜둬야 하고, 터미널을 닫으면 주소가 사라짐 (매번 주소가 바뀜)

어차피 진행자 화면을 노트북에서 여실 거라, 파티 한 번 하는 용도로는 이 방법이 가장 편합니다.

### 방법 B. Render 에 배포 (고정 주소가 필요할 때)

저장소에 `render.yaml` 이 들어 있어 클릭 몇 번이면 됩니다.

1. 이 저장소를 GitHub 에 올립니다.
2. [render.com](https://render.com) 가입 → **New +** → **Blueprint** → 저장소 선택
3. `ADMIN_PASSWORD` 값을 물어보면 **직접 정한 비밀번호**를 입력 (필수)
4. 배포가 끝나면 `https://quiz-quiz-xxxx.onrender.com` 주소가 생깁니다

- 👍 고정 주소, 노트북을 꺼도 동작
- 👎 무료 플랜은 **접속이 없으면 잠들고**, 깨어날 때 30~60초 걸립니다.
  더 중요한 건 **잠들었다 깨면 컨테이너가 새로 뜨면서 점수가 초기화**된다는 점입니다
  (무료 플랜은 디스크가 유지되지 않습니다).

  → 퀴즈 시작 **몇 분 전에 미리 주소를 열어 서버를 깨워두세요.** 게임 중에는 계속 통신이
  오가서 잠들지 않습니다. 점수가 꼭 보존되어야 한다면 유료 플랜의 영구 디스크를 `/app/data`
  에 붙이거나, 방법 A 를 쓰세요.

### 방법 C. 도커를 받는 곳 어디든

`Dockerfile` 이 들어 있어 **Fly.io · Railway · Koyeb · Cloud Run** 등에 그대로 올릴 수 있습니다.
점수를 계속 보존하려면 `/app/data` 에 영구 볼륨을 붙이세요.

### 배포할 때 꼭 지킬 것

- **`ADMIN_PASSWORD` 환경변수를 반드시 설정하세요.** 기본 비밀번호(`admin1234`)는 공개된 값이라,
  그대로 두면 아무나 `/admin` 에 들어와 진행을 가로챌 수 있습니다.
  `NODE_ENV=production` 에서 기본 비밀번호를 쓰면 **서버가 아예 실행되지 않도록** 막아두었습니다.
- **인스턴스는 1개로 유지하세요.** Socket.IO 연결이 서버 한 대에 붙어 있어야 하므로,
  여러 대로 늘리면 참가자마다 다른 서버에 붙어 게임이 갈라집니다.
- 참가자 주소는 아는 사람에게만 공유하세요. 지금은 주소만 알면 누구나 닉네임을 넣고 들어올 수 있습니다.
  (입장 코드가 필요하면 추가할 수 있습니다.)

> 무료 플랜 조건은 서비스마다 자주 바뀌니, 배포 전에 해당 사이트에서 현재 정책을 확인해 주세요.

## 진행 흐름

1. 친구들이 접속해서 **닉네임**을 입력합니다.
2. 대기 화면에 **4×4 = 16칸**이 뜹니다. 각 칸에는 **타이틀과 부제목**이 적혀 있어요.
   화면 아래에는 **지금 들어와 있는 친구들의 목록**이 실시간으로 표시됩니다.
3. 참가자가 궁금한 칸을 누르면 **하트가 실시간으로 올라가고 하트 이모지가 뿅뿅** 나타났다 사라집니다.
   하트 수치는 **모든 사람에게 동시에** 보입니다.
4. 진행자는 하트가 많이 모인 칸(붉은 테두리로 강조)을 보고 다음 문제를 고릅니다.
5. 진행자가 출제하면 참가자 화면에 **"3초 뒤 문제가 출제됩니다"** 팝업이 뜬 뒤 문제가 시작됩니다.
6. 제한시간이 **끝나기 5초 전 힌트**가 공개됩니다.
7. **제출하기**를 누르거나 **제한시간이 끝나면 자동 제출**됩니다.
8. 채점 후 이번 문제 순위와 획득 점수가 공개됩니다.

## 점수 규칙

| 순위 | 점수 |
| --- | --- |
| 1등 | **5점** |
| 2~4등 | **2점** |
| 그 외 정답자 | **1점** |
| 오답 · 미제출 | 0점 |

- 순위는 **제출하기를 누른 시각** 기준입니다 (서버에서 측정).
- 특정 문제에 **2배 점수**를 걸면 위 점수가 전부 2배가 됩니다.
- 점수 규칙은 진행자 콘솔의 **설정** 탭에서 언제든 바꿀 수 있습니다.

## 문제 유형

| 유형 | 설명 | 순위 기준 |
| --- | --- | --- |
| ⚡ **선착순 객관식** | 보기를 골라 제출 | 정답자 중 **먼저 낸 순** |
| 🔊 **음성 퀴즈** | 보기마다 음성을 붙이고, 들어본 뒤 정답 고르기 | 정답자 중 **먼저 낸 순** |
| ✏️ **주관식** | 정답을 직접 입력 (띄어쓰기·대소문자·문장부호 무시, 복수 정답 가능) | 정답자 중 **먼저 낸 순** |
| 🧩 **퍼즐 매칭** | 왼쪽·오른쪽 카드를 연결. 연결하면 **선으로 이어져** 한눈에 보임 | **맞힌 개수** → 같으면 먼저 낸 순 |
| 🎯 **근사치 맞추기** | 정답에 가까울수록 높은 점수 (**선착순 아님**) | **차이가 작은 순** → 같으면 먼저 낸 순 |

**객관식·음성 퀴즈의 보기 개수**는 편집 화면에서 `＋ 보기 추가` / `✕` 로 자유롭게
늘리고 줄일 수 있습니다. (2개~8개)

**퍼즐**은 전부 맞히지 못해도 **맞힌 개수만큼 부분 점수**를 받습니다. 연결한 카드는
색깔 있는 선으로 이어져 무엇과 무엇을 이었는지 바로 보입니다.
처음 보면 조작법이 헷갈리므로, 진행자가 **🧩 퍼즐 연습 화면**으로 미리 연습시킬 수 있어요.

**근사치 맞추기**는 두 가지 방식이 있습니다.

- 💰 **가격·숫자 맞추기** — 휴대폰 키보드 대신 **계산기 같은 숫자 버튼**으로 입력합니다.
- 📅 **날짜 맞추기** — 년/월/일을 **위아래로 굴리는 스크롤 휠**로 고릅니다.

## 사진 · 음성 첨부

| 어디에 | 무엇을 |
| --- | --- |
| 문제 본문 | 사진 (모든 유형) |
| 객관식·음성 보기 하나하나 | 사진, 음성 |
| 퍼즐 카드 하나하나 | 사진 |

사진은 **파일 선택 · 붙여넣기(Ctrl/⌘+V) · 끌어다 놓기** 셋 다 됩니다.
관리자 브라우저에서 자동으로 리사이즈·압축(최대 900px)해 문제 데이터에 함께 저장하므로
**별도의 이미지 서버가 필요 없습니다.**

음성은 압축할 수 없어 원본 그대로 저장되니 **한 개당 2.8MB 이하**로 잘라서 올려주세요.
(그보다 크면 안내 메시지가 뜨고 등록되지 않습니다.)

## 결과 화면 해설

채점이 끝나면 참가자 화면에 정답과 함께 **해설**이 표시됩니다.

- **객관식·음성** — 1번부터 끝번까지 **모든 보기를 다시 보여주고** 정답을 초록색으로 강조합니다.
  음성 보기는 결과 화면에서 **다시 들어볼 수 있어요.**
- **퍼즐** — **정답 짝을 전부** 보여주고, 내가 연결한 것과 맞는지 짝마다 ⭕️ / ❌ 로 표시합니다.
- **근사치** — 정답 값을 크게 보여주고, 순위표에 사람마다 **얼마나 차이났는지**와
  **무엇을 적어냈는지**를 함께 보여줍니다.
- 문제마다 **해설** 문구를 따로 적어두면 그 아래에 함께 표시됩니다 (비워두면 숨겨집니다).

누르면 **모든 참가자와 진행자 화면에 동시에** 떠오릅니다.
스티커 그림은 `public/img/stickers/*.png` 에 들어 있고, 바꾸고 싶으면 같은 이름으로
파일만 교체하면 됩니다.

- 화면 아래에서 **채팅처럼 위로 떠오르고**, 문제를 가리지 않도록 **최대 130px 까지만** 올라갑니다.
- 등장할 때 **스프링 애니메이션**(살짝 튕기며 커짐), 사라질 때 **0.3초 페이드 아웃**.
- 동시에 **최대 5개**까지만 보이고, 넘치면 가장 오래된 것부터 사라집니다.
- 도배를 막기 위해 한 사람당 **초당 4회**로 제한됩니다.
- 진행자 화면에서는 오른쪽 아래에 모여 뜹니다 (진행자는 보기 전용).

## 입장 대기 화면

문제가 시작되기 전 대기 화면에는 **지금 들어와 있는 친구들의 명단**이 표시됩니다.
새로운 사람이 들어오면 실시간으로 갱신되고, 내 이름은 강조되어 보입니다.
연결이 끊긴 사람은 흐리게 표시됩니다.

## 중간 이탈 & 재접속

브라우저를 닫거나 연결이 끊겨도, **같은 닉네임으로 다시 입장하면 기존 점수를 그대로 이어받습니다.**
닉네임은 앞뒤 공백과 대소문자를 무시하고 같은 사람으로 인식합니다.
문제가 진행 중일 때 다시 들어오면 **진행 중인 문제 화면으로 바로 합류**합니다.

## 진행자 기능

**진행 탭**
- 16칸의 하트 수치를 실시간으로 확인 (하트가 많은 칸은 붉은 테두리)
- 칸별 **출제하기 / 2배 점수 토글 / 편집 / 출제기록 표시**
- 진행 중 패널: 남은 시간, 제출 인원, **바로 채점하기**, 진행 중 2배 전환
- 🏆 **순위 공개** — 원할 때 전체 순위를 모든 참가자 화면에 띄우고 닫기
- 🧩 **퍼즐 연습 화면** 열기/닫기
- 🔙 보드로 돌아가기

**문제 편집 탭**
- 16칸 각각의 타이틀 · 부제목 · 유형 · 문제 내용 · 제한시간 · **힌트** · **해설** · 2배 점수 편집
- 객관식 보기와 정답, 주관식 복수 정답, 퍼즐 짝(최대 6쌍) 설정
- 문제 본문 · 객관식 보기 · 퍼즐 카드마다 이미지 첨부 (파일 선택 또는 붙여넣기)
- **저장하고 바로 출제** 버튼

**설정 탭**
- 점수 규칙, 카운트다운 초, 힌트 공개 시점 변경
- 하트 / 출제기록 / 점수 / 참가자 초기화 (문제 내용은 보존됩니다)

**사이드 패널**
- 참가자 목록과 점수, 접속 상태, 점수 수동 ±조정, 참가자 삭제

## 기술 메모

- **Node.js + Express + Socket.IO**, 프론트는 의존성 없는 바닐라 JS
- 문제·점수·하트는 `data/state.json`에 자동 저장되어 **서버를 재시작해도 유지**됩니다
- 정답은 채점 전까지 클라이언트로 내려보내지 않습니다. 힌트도 공개 시점에 서버가 전송합니다
- 순위 기준 시각은 **서버에서 측정**하므로 휴대폰 시계가 달라도 공정합니다
- 하트 연타는 초당 10회로 제한되고, 브로드캐스트는 120ms 단위로 묶어 보냅니다
- 웹·모바일 반응형 (320px 소형 휴대폰부터 데스크톱까지 확인)

### 구조

```
server/
  index.js        게임 진행 로직 + Socket.IO 이벤트
  defaultQuiz.js  기본 16문제 · 점수 규칙 · 연습용 퍼즐
  store.js        data/state.json 저장/복원
public/
  index.html      참가자 화면
  admin.html      진행자 콘솔
  css/app.css
  js/player.js    참가자 로직
  js/admin.js     진행자 로직
  js/common.js    공용 유틸 (시계 동기화, 토스트 등)
```
