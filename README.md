# 🎉 퀴즈퀴즈 (Quiz-Quiz)

친구들과 함께 즐기는 **실시간 파티 퀴즈**.
참가자는 휴대폰으로, 진행자는 노트북으로 접속합니다.

---

## 빠른 시작

```bash
npm install
npm start
```

서버가 켜지면 터미널에 접속 주소가 표시됩니다.

| 역할 | 주소 |
| --- | --- |
| 참가자 (휴대폰) | `http://<노트북IP>:3000` |
| 진행자 (노트북) | `http://<노트북IP>:3000/admin` |

친구들과 **같은 와이파이**에 연결한 뒤 참가자 주소를 알려주세요.
밖에서 접속해야 한다면 `ngrok http 3000` 같은 터널링 도구를 쓰면 됩니다.

관리자 비밀번호 기본값은 `admin1234` 입니다. 바꾸려면:

```bash
ADMIN_PASSWORD=원하는비밀번호 PORT=3000 npm start
```

## 진행 흐름

1. 친구들이 접속해서 **닉네임**을 입력합니다.
2. 대기 화면에 **4×4 = 16칸**이 뜹니다. 각 칸에는 **타이틀과 부제목**이 적혀 있어요.
3. 참가자가 궁금한 칸을 누르면 **하트가 실시간으로 올라가고 하트 이모지가 뿅뿅** 나타났다 사라집니다.
   하트 수치는 **모든 사람에게 동시에** 보입니다.
4. 진행자는 하트가 많이 모인 칸(붉은 테두리로 강조)을 보고 다음 문제를 고릅니다.
5. 진행자가 출제하면 참가자 화면에 **"3초 뒤 문제가 출제됩니다"** 팝업이 뜬 뒤 문제가 시작됩니다.
6. 제한시간이 **끝나기 5초 전 힌트**가 공개됩니다.
7. **제출하기**를 누르거나 **제한시간이 끝나면 자동 제출**됩니다.
8. 채점 후 이번 문제 순위와 획득 점수가 공개됩니다.

## 점수 규칙

| 순위 | 점수 |
| --- | --- |
| 1등 | **5점** |
| 2~4등 | **2점** |
| 그 외 정답자 | **1점** |
| 오답 · 미제출 | 0점 |

- 순위는 **제출하기를 누른 시각** 기준입니다 (서버에서 측정).
- 특정 문제에 **2배 점수**를 걸면 위 점수가 전부 2배가 됩니다.
- 점수 규칙은 진행자 콘솔의 **설정** 탭에서 언제든 바꿀 수 있습니다.

## 문제 유형

| 유형 | 설명 |
| --- | --- |
| ⚡ **선착순 객관식** | 보기를 골라 제출. 먼저 정답을 낸 사람이 높은 점수 |
| ✏️ **주관식** | 정답을 직접 입력. 띄어쓰기·대소문자·문장부호는 무시하고 채점하며, 복수 정답 등록 가능 |
| 🧩 **퍼즐 매칭** | 왼쪽 카드를 누른 뒤 오른쪽 카드를 눌러 짝을 연결. 모두 맞아야 정답 |

퍼즐은 처음 보면 조작법이 헷갈리므로, 진행자가 **🧩 퍼즐 연습 화면**을 눌러
점수와 무관한 **연습하기 화면**을 미리 띄워줄 수 있습니다.

## 중간 이탈 & 재접속

브라우저를 닫거나 연결이 끊겨도, **같은 닉네임으로 다시 입장하면 기존 점수를 그대로 이어받습니다.**
닉네임은 앞뒤 공백과 대소문자를 무시하고 같은 사람으로 인식합니다.
문제가 진행 중일 때 다시 들어오면 **진행 중인 문제 화면으로 바로 합류**합니다.

## 진행자 기능

**진행 탭**
- 16칸의 하트 수치를 실시간으로 확인 (하트가 많은 칸은 붉은 테두리)
- 칸별 **출제하기 / 2배 점수 토글 / 편집 / 출제기록 표시**
- 진행 중 패널: 남은 시간, 제출 인원, **바로 채점하기**, 진행 중 2배 전환
- 🏆 **순위 공개** — 원할 때 전체 순위를 모든 참가자 화면에 띄우고 닫기
- 🧩 **퍼즐 연습 화면** 열기/닫기
- 🔙 보드로 돌아가기

**문제 편집 탭**
- 16칸 각각의 타이틀 · 부제목 · 유형 · 문제 내용 · 제한시간 · **힌트** · 2배 점수 편집
- 객관식 보기와 정답, 주관식 복수 정답, 퍼즐 짝(최대 6쌍) 설정
- **저장하고 바로 출제** 버튼

**설정 탭**
- 점수 규칙, 카운트다운 초, 힌트 공개 시점 변경
- 하트 / 출제기록 / 점수 / 참가자 초기화 (문제 내용은 보존됩니다)

**사이드 패널**
- 참가자 목록과 점수, 접속 상태, 점수 수동 ±조정, 참가자 삭제

## 기술 메모

- **Node.js + Express + Socket.IO**, 프론트는 의존성 없는 바닐라 JS
- 문제·점수·하트는 `data/state.json`에 자동 저장되어 **서버를 재시작해도 유지**됩니다
- 정답은 채점 전까지 클라이언트로 내려보내지 않습니다. 힌트도 공개 시점에 서버가 전송합니다
- 순위 기준 시각은 **서버에서 측정**하므로 휴대폰 시계가 달라도 공정합니다
- 하트 연타는 초당 10회로 제한되고, 브로드캐스트는 120ms 단위로 묶어 보냅니다
- 웹·모바일 반응형 (320px 소형 휴대폰부터 데스크톱까지 확인)

```
  js/admin.js     진행자 로직

```
